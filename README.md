*Task01 - Rule-Based AI Chatbot*

A simple rule-based chatbot built in Python using if-else logic.

Features
Handles greetings (hi, hello, hey)
Responds to small talk (how are you, your name, help, weather)
Runs in a continuous loop until an exit command (bye, exit, quit)
How to Run
bash
python rule_based_chatbot.py
Skills Used

Control flow, decision-making logic, basic AI concepts.
