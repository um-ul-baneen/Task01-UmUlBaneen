# Task01 - Um-ul-Baneen

Mini AI/Python projects completed as part of internship task 1.

## Projects

1. **Rule-Based Chatbot** (`rule_based_chatbot.py`)
   Simple chatbot using if-else logic. Handles greetings, small talk, and exit commands in a loop.

2. **Data Classification** (`data_classification.py`)
   Loads the Iris dataset, splits into train/test sets, trains a K-Nearest Neighbors classifier, and evaluates accuracy.

3. **Random Password Generator** (`password_generator.py`)
   Takes a user-specified length and generates a random password using letters, numbers, and symbols.

4. **Text Recognition (OCR)** (`text_recognition.py`)
   Generates a sample image with text, then uses Tesseract OCR to recognize and extract the text.

## How to Run

```bash
python rule_based_chatbot.py
python data_classification.py
python password_generator.py
python text_recognition.py
```

## Requirements

```bash
pip install scikit-learn pandas pytesseract pillow
```
Text recognition also needs Tesseract OCR installed on the system.
